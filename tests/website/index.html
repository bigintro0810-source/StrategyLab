STRATEGY LAB

TradingViewとEA Studioを融合し、それらを超える自由度を。

条件は人が組むのではなく、エンジンが自動生成する。何百〜何万通りの売買ルールを生成し、 バックテストで篩にかけ、生き残った戦略だけをWalk Forward・Out-of-Sample・モンテカルロで検証する。

Pipeline

戦略は、人ではなくエンジンが探す。

手で1つずつ組み立てるのではなく、条件の「部品」を渡せば、あとはエンジンが構造そのものを探索する。

01

条件プールを定義

EMA・RSI・ATR・一目均衡表・ICT/SMC・ローソク足パターンなど、100種を超える指標/条件をあらかじめ用意。

→
02

構造を自動生成

AND/OR/NOTで組み合わせた条件ツリーを、ランダム生成または遺伝的アルゴリズムでエンジン自身が組み立てる。

→
03

大量にバックテスト

生成した候補を並列実行。スプレッド・スリッページ・手数料まで含めた実行条件を再現して検証する。

→
04

指標でランキング

Profit Factor・最大DD・シャープレシオ・リカバリーファクターなど複数指標で自動評価・順位付け。

→
05

生存者だけを堅牢性検証

上位候補のみ、Walk Forward・Out-of-Sample・モンテカルロ・パラメータ安定性で仕上げの検証をかける。

Engine

手動でも、自動でも。両方使えるビルダー。

条件を自分で組みたい日も、エンジンに任せたい日も、同じプラットフォームの上でどちらも動く。

MANUAL

手動探索

条件ツリーエディタでAND/OR/NOTを自在に組み合わせ、ロング・ショート・両方を自由に切り替えて1つの戦略をじっくり作り込む。

AUTO

自動探索

ランダム生成と遺伝的アルゴリズムの2モードを搭載。世代を重ねるごとに、より良い成績の条件構造へと進化していく。

EXECUTION

実行条件まで再現

Validation

「勝てそう」で終わらせない。

ランキング上位というだけでは、たまたま良い結果が出ただけかもしれない。4つの角度から頑健性を確かめる。

Out-of-Sample

学習期間と検証期間を分離し、見せていないデータでも成績が再現するかを確認する。

Walk Forward

検証期間を少しずつずらしながら繰り返し評価し、特定の相場環境への過剰適合を検出する。

モンテカルロ

取引の並び順をシャッフルして多数回試行し、結果が偶然の順序に依存していないかを統計的に検証する。

パラメータ安定性

数値を少し動かしただけで成績が崖から落ちるように悪化しないか、周辺パラメータでの安定度を確認する。

Export

見つけた戦略を、そのままTradingViewへ。

採用した条件ツリーをPine Scriptへ自動変換。エントリー・決済・トレーリングまで再現したストラテジースクリプトとして書き出し、 使い慣れたTradingViewのチャート上でそのまま確認できる。 

// StrategyX が自動生成
strategy("SL_20260728_auto", overlay=true)

ema200 = ta.ema(close, 200)
rsi14  = ta.rsi(close, 14)

longCond = close > ema200 and rsi14 < 35
if (longCond)
    strategy.entry("Long", strategy.long)
